What This Is

13 production-ready demo sites for local businesses with zero or minimal web presence. Each demo is a fully functional, responsive HTML website optimized for mobile (320–1440px) and desktop, ready to be handed to a real business owner as a starting point.

Built using Hallmark design principles—anti-AI-slop design methodology ensuring each site has unique structure, genuine copy, and business-specific visual identity instead of template homogeneity.

✓ Ready to Deploy

All demos are stored in /docs/ directory. To view them live:

  1. Go to your repository Settings → Pages
  2. Set Source to deploy from /docs on your current branch
  3. GitHub Pages will host all demos automatically

Until then, click links below to view each demo's raw HTML in your browser
